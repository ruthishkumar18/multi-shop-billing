# Multi-Shop Billing Management System

A complete, production-grade **Billing Management System** designed for grocery stores, stationery shops, supermarkets, retail traders, and wholesale merchants. The system features a centralized **Admin Console** for managing shop accounts, paired with individual, isolated **Customer Shop Workspaces** for fast counter invoicing, product catalogue management with units, printable invoices, WhatsApp & SMS sharing, and audit billing history.

## 🗄️ Step 1: Initialize Database in MySQL Workbench

The project includes `schema.sql` pre-configured for local MySQL with user `root` and no password.

1. Open **MySQL Workbench**.
2. Connect to your local MySQL instance:
   - **Hostname**: `localhost` (or `127.0.0.1`)
   - **Port**: `3306`
   - **Username**: `root`
   - **Password**: *(Leave blank if you have no password, or enter your MySQL root password)*
3. Click **File > Open SQL Script...** (or press `Ctrl + O`) and select `schema.sql` from the extracted folder.
4. Press **`Ctrl + A`** to highlight the entire script.
5. Click the **Execute (Lightning Bolt icon)** at the top of the query editor.

> ℹ️ **Note on `1051 Unknown table` warnings:**
> You may see warnings like `DROP TABLE IF EXISTS ... 1 warning(s): 1051 Unknown table 'billing_db.users'`.
> This is completely **normal and expected** when executing the script on a fresh database, because the tables did not exist yet to drop. The script automatically creates all 5 tables and seeds the Master Administrator account.
> 
> Once finished, the **Result Grid** at the bottom will display the newly created `admin` record.

## 🚀 Step 2: Running on 1 Port (Single-Port Unified Mode)

No need to open two terminals or manage two separate ports! The backend is configured to **directly serve both the Frontend UI and Backend APIs together on a single port (Port 5000)**. Whenever you run the backend, it connects the frontend automatically.

### 🌟 Method A: 1-Click Launch (Windows)
Double-click the included batch file:
```cmd
run_app.bat
```
This script automatically:
1. Checks and installs required Python packages (`pip install -r requirements.txt`).
2. Checks that the frontend production bundle is ready in `dist/` (builds it if missing).
3. Automatically opens **`http://localhost:5000`** in your default browser.
4. Starts the unified server connecting frontend and backend on **Port 5000**!

## 🛠️ Troubleshooting & Frequently Asked Questions

### 1. `npm error code ERESOLVE` during `npm install`
- **Solution**: Run `npm install --legacy-peer-deps` or ensure your `package.json` contains `"esbuild": "^0.28.0"`.

### 2. Can't connect to MySQL (`Access denied for user 'root'@'localhost'`)
- If your MySQL `root` user has a password set, open `.env` (for Flask) and specify:
  ```env
  DB_PASSWORD=your_actual_password
  ```
  In MySQL Workbench, enter that same password when connecting.

### 3. Port `3000` or `5000` is already in use
- If port `3000` is busy, Vite will automatically select the next available port (e.g. `3001`). Check the terminal output for the active URL.
- For Flask, you can specify a different port in `.env` (e.g., `PORT=5001`).

### 4. How do customers register?
- Customers **cannot self-register** by design. To prevent unauthorized access, all customer accounts must be created by the System Administrator in the **Admin Console**.
